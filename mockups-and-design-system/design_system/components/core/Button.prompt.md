**Button** — the primary action control; uppercased terminal type, phosphor glow on the primary variant.

```jsx
<Button variant="primary" size="md" onClick={run}>Start Run</Button>
<Button variant="secondary">Change Mode</Button>
<Button variant="ghost" size="sm">Skip</Button>
<Button variant="danger">Abort</Button>
```

Variants: `primary` (filled green), `secondary` (outlined), `ghost` (bare), `danger` (red). Sizes `sm|md|lg`; `block` stretches full width; `disabled` dims to 40%.
