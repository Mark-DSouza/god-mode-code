**ChallengeCard** — a category tile for the three challenge types (motivational quotes, coding blocks, literary prose).

```jsx
<ChallengeCard glyph="❝❞" title="Quotes" description="Motivational one-liners" meta="240 passages" selected onClick={pick} />
```
Composes `Card` + `Badge`. `glyph` renders large in CRT green.
